# 004-少年夜话 · 设计说明

> 创建：2026-08-24 ｜ 维护人：沐弦 ｜ 状态：🟢 已上线

## 1. 目标与边界

- **目标**：每天北京时间 20:00，自动产出一段「男孩第一人称」口吻、~300 字的中文故事，
  并用中文男声朗读成音频，文本 + 音频推送到指定 Telegram chat（支持多个）。
- **技术栈**：Cloudflare Worker + Workers AI（文本生成）+ KV + Cron；TTS 用 Microsoft
  Edge TTS（免费、无需 key，因该账号的 Workers AI 无可用中文男声）。
- **风格约束**：温暖、积极、有想象力；**明确禁止**恐怖、血腥、惊悚、暴力、灵异、阴暗内容。

## 2. 架构

```
Cron(UTC 12:00 == 北京 20:00)  /  Telegram /story (webhook)
        │
        ▼
scheduled() ──► runOnce(env)
                    │
        ┌───────────┼───────────────┐
        ▼           ▼               ▼
   KV 防重发    Workers AI        Edge TTS
   (last_date)  文本生成           (云夏男声,
                (llama-3.3)         WebSocket)
                    │               │
                    └──────┬────────┘
                           ▼
                  Telegram Bot API
              sendAudio(MP3, caption=标题+风格)
              sendMessage(正文文本)
                           │
                           ▼
                  KV 存档(latest / last_date)
```

- 单 Worker，模块格式（`export default { scheduled, fetch }`）。
- 文本来自 Workers AI；音频来自 Edge TTS（若 TTS 失败，降级为纯文本推送，保证不中断）。
- 推送分两条：音频（caption 带标题+风格）+ 正文文本，规避 caption 1024 字上限。

## 3. 关键技术决策（已实测验证）

| 项 | 决策 | 依据 |
|----|------|------|
| 定时时区 | Cron `0 12 * * *`（UTC） | Cloudflare Cron 仅 UTC；中国无夏令时，全年稳定 |
| 文本模型 | `@cf/meta/llama-3.3-70b-instruct-fp8-fast` | 中文质量好；回退 `llama-3.1-8b-instruct` |
| 中文 TTS | **Edge TTS** + `zh-CN-YunxiaNeural`（云夏，男孩音） | 账号内无 Kokoro、MeloTTS 返回 500、Deepgram 仅英文；Edge TTS 免费且确有中文男声 |
| Edge TTS 握手 | `https://` + `Upgrade: websocket` + 浏览器 `User-Agent` | Workers `fetch` 不认 `wss://`；实测仅需 UA 即可通过握手 |
| 多 Chat | `TELEGRAM_CHAT_IDS` 逗号分隔 | 环境变量配置，支持多个目标 |
| 防重发 | KV `last_date` = 北京日期 | 自然日去重；`/test` 强制发送绕过 |
| 手动触发 | Telegram `/story`（webhook）+ `GET /test` | 双通道手动触发 |

## 4. 可调整项

- **风格池** `STORY_STYLES`：10 种温暖风格。
- **男孩名字池** `BOY_NAMES`：影响第一人称叙事者名字。
- **男声选择** `TTS_VOICE`：`zh-CN-YunxiaNeural`(云夏/男孩) / `zh-CN-YunxiNeural`(云希/青年男) 等。
- **故事字数**：system 指令「约 300 字」可改。
- **推送时间**：改 `wrangler.toml` 的 `crons`（仍按 UTC 写）。

## 5. 风险与回退

- **Edge TTS 是非官方免费接口**：无 key、无需注册，但微软可能调整协议导致失效；
  届时需替换 TTS（或改用 Cloudflare AI 中文 TTS，但音色为女声且当前账号不可用）。
- **Workers 外连 WebSocket**：必须用 `https://` + `Upgrade: websocket`（`wss://` 会被 fetch 拒绝）。
- **文本模型响应结构不稳定**：`extractContent()` 已兼容字符串 / OpenAI `choices` 等多种返回形状。
